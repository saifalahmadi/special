## How to Contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes with clear, descriptive commit messages.
4. Open a pull request describing your changes.

## Code of Conduct

All contributors are expected to maintain a respectful and inclusive environment. Harassment or abusive behavior of any kind will not be tolerated.

## Reporting Issues

Please open a GitHub issue to report bugs or suggest features. Include as much detail as possible.

## Questions

For general questions, open an issue and label it as a question.
